# ADR-001: Рефакторинг системи видачі книг до Rich Domain Model із застосуванням GRASP## СтатусПрийнято (Accepted)## КонтекстУ вихідному коді `variant4_librarymanagement` процес видачі книг реалізовано монолітним методом `LegacyLibraryProcessor.issueBookFromConsole()`. Сутності `Reader`, `Book` та `LoanRecord` є анемічними (Anemic Domain Model) з публічними полями. Логіка обчислення застави та збору реалізована через каскадні `if-else` перевірки за текстовим типом категорії книги. Консольний UI жорстко зв'язаний із бізнес-математикою, логуванням та симуляцією надсилання email.## РішенняПровести комплексний рефакторинг за методологією GRASP:1. **Rich Domain Model (Information Expert, Creator):** * Закрити публічні поля сутностей `Reader`, `Book`, `LoanRecord`. Надати приватні сеттери та конструктори. * Перенести перевірку ліміту активних видач у `Reader`. * Перенести розрахунок вартості та конструювання у `LoanRecord` / фабричні методи.2. **Polymorphism & Protected Variations:** * Виділити інтерфейс `LoanPolicyStrategy` для поліморфного розрахунку застави та збору залежно від категорії книги (`StandardPolicy`, `RarePolicy`, `AcademicPolicy`).3. **Controller, Indirection & Pure Fabrication:** * Виділити тонкий `BookIssuanceController` (Application Service) для координації сценарію. * Виділити технічні класи `AuditLogger` та `EmailNotificationService` (Pure Fabrication) та сховати їх за інтерфейсами (Indirection). * Очистити UI (Console CLI) від бізнес-логіки, залишивши лише введення/виведення.## Наслідки### Позитивні* **Low Coupling:** Окремі шари системи ізольовані, CBO для доменних сутностей та контролера не перевищує target-рівень CBO ≤ 4.* **High Cohesion:** Кожен клас виконує лише одну чітко визначену роль (LCOM4 = 1).* **Розширюваність:** Додавання нової категорії книги (наприклад, "Manuscript") потребує створення лише одного нового класу політики без зміни існуючого коду.### Компроміси / Негативні* Збільшення загальної кількості класів та файлів у проєкті за рахунок впровадження інтерфейсів та моделей стратегій.
